# Clobas Teardown — Evidence Folder

This folder documents why the current school portal (Clobas) is being replaced.
It is written to be **shown to teachers and school staff**.

## Contents

- **`friction-log.md`** — the main document: section-by-section problems in bullet form,
  each tied to a screenshot, ending with the design rules our replacement commits to.
  *Start here.*
- **`../ux-teardown.md`** — the working teardown used during development (failure log →
  design rules). Updated as new evidence arrives.
- **`screenshots/`** — 20 captures of the live portal (16 Sep 2026).
  Named files are verified; `unlabeled-*.png` are awaiting identification.

## How to use with a teacher

1. Open `friction-log.md` (or print it).
2. Walk one section at a time; each links to its screenshot.
3. The ask at the end: feedback on the **design rules** — would these fix the daily pain?
